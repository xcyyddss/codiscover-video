# 公开示例与数据边界

CoDiscover Video 的公开版本只包含项目编写的合成素材与可重复运行的场景，不携带作者或用户的真实观看记录、对话、账号、字幕、画面帧或本机数据库。示例采用与应用相同的模型契约、任务状态机、检索器和反馈存储，但数据源与推理引擎均固定为 `demo`。

## 一次运行，观察完整闭环

在仓库根目录安装依赖后运行：

```bash
uv sync --frozen
uv run python scripts/run_example.py
```

可将结果保存在被 Git 忽略的运行目录：

```bash
uv run python scripts/run_example.py --output data/example-result.json
```

示例不会读取 `.env`、不会登录 B 站、不会请求模型 API，也不会复用当前工作台的数据库。它在临时目录中建立 SQLite，完成后自动清理。即使你的 shell 已配置真实模式，示例也使用显式构造的演示设置。

输出是稳定的 JSON，省略随机数据库标识、真实时钟、机器路径和性能数字。提交的 [expected.json](after_work/expected.json) 是脚本实际执行得到的参考结果，而不是手写的推荐答案。测试会逐项比较它与重新执行的结果。

## “下班后的十分钟”场景

场景输入见 [scenario.json](after_work/scenario.json)。用户和反馈均为虚构。

| 步骤 | 输入或动作 | 应观察到的行为 |
| --- | --- | --- |
| 提出模糊期待 | “下班后，我还不确定想看什么” | 保存目标和使用场景，尚不把用户固定为某种类型 |
| 离线探索 | 一轮最多分析 6 条素材 | 任务规划搜索词、搜索、读取合成字幕、生成规则摘要、分块入库，并保存阶段记录 |
| 澄清方向 | 喜欢安静自然观察，也想试试轻度科普，拒绝游戏和高刺激 | 对话更新可检查的偏好，并保留需要实际体验验证的假设 |
| 看理由与证据 | 获取当前目标的推荐 | 结果附带证据来源；匹配到标题/简介时标为 `metadata`，命中虚构字幕时标为 `demo_subtitle` |
| 表达不适合当前场景 | 对 `demo-science` 评 2 分：下班后仍不想理解概念 | 该视频从当前目标的推荐中排除 |
| 改变使用目标 | 另建“周末学习简单科学”的目标 | 同一条视频仍可推荐，说明负反馈没有变成全局黑名单 |
| 无视频自由反馈 | 记录“此刻更想要安静陪伴” | 反馈保存到当前目标，`video_id` 为 `null`，不会伪造观看记录 |

输出末尾的 `checks` 均应为 `true`。`model_http_calls` 为 0，因为这里演示的是本地确定性规则与工程流程，不是实际大模型推理。实例没有自称“已经让用户放松”，也不推断真实心理效果。

## 哪些数据适合放进仓库

| 内容 | 公开策略与理由 |
| --- | --- |
| [12 条合成视频语料](../src/codiscover_video/fixtures/demo_videos.json) | 保留。包含虚构 ID、标题、作者昵称、标签、简介及时间片段；便于不依赖账号的安装、测试与演示 |
| 场景输入与预期输出 | 保留。让读者看清从需求到反馈的行为差异，并可复现对比 |
| 合成工作台截图 | 保留。仅展示上述合成内容与公开界面 |
| 配置字段示例 | 保留 `.env.example`，API Key 留空，不放可用凭证 |
| 真实平台字幕、画面、下载媒体 | 不保留。避免把外部作者内容与本项目原创示例混淆；真实模式由使用者自行读取 |
| 用户目标、聊天、反馈、浏览记录、导出 JSON | 不保留。可能暴露个人偏好与使用场景；只在本机运行目录保存 |
| `.env`、B 站 Cookie/凭证、二维码、数据库、日志、付费 API 响应 | 不保留。既不是可移植的示例，也不应随源代码分发 |

语料文件采用 `schema_version: 1`、`synthetic: true` 和 `provenance` 标识，使用与项目一致的 MIT 许可。所有作者昵称都是虚构标签，没有作者 UID；`url` 和 `image_urls` 均为空，`demo-*` 不指向真实平台视频。包内这份 JSON 是唯一语料源，源码运行与安装 wheel 后运行使用相同文件。

`content_status: "subtitle"` 表示数据形状具备文字片段，**不是宣称这些文本来自真实视频**；`source: "demo"` 与每段 `source: "demo_subtitle"` 才是其明确来源。样本时间是为演示写定的相对时间，并非采集记录。若某次推荐只有 `metadata` 证据，其 `0–0` 时间不表示真实视频的第零秒。

## 如何修改示例

1. 在包内 `demo_videos.json` 修改素材，保留合成标识、`demo-*` ID、空媒体地址与有效时间范围。
2. 在场景 JSON 修改虚构输入，不复制真实用户对话或平台响应。
3. 执行脚本检查行为，必要时重新生成预期文件：

   ```bash
   uv run python scripts/run_example.py --output examples/after_work/expected.json
   uv run pytest tests/test_example.py -q
   ```

4. 审阅预期输出的行为差异。不要只为了让断言通过而把失败结果替换为新的“标准答案”。

这组小型固定语料用于功能回归，不能据此声称真实推荐准确率、满意度改善、用户研究结论或线上性能收益。真实效果评估需要独立查询、人工标注和明确授权的数据。
