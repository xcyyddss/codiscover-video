## 本次发布特别检查的边界

- `.env` 只从当前启动目录读取，不能因仓库放在另一个项目下而继承父目录账号配置。显式 shell 环境变量仍按用户配置生效。
- 合成示例直接构造演示模式设置，不读取 `.env`；测试阻断网络和真实模型/平台调用，并验证已设置真实模式的环境也不会影响示例。
- 浏览器测试默认使用独立端口、拒绝复用已有服务，并检查项目标题与 `demo/demo` 模式，防止测试误写其他工作台。
- 公开语料使用 `synthetic: true`、`demo-*` ID、虚构作者及空媒体地址。字幕形状具有相对时间，但不代表抓取过真实视频。
- 保留的截图重新取自新名称下的合成演示，不使用登录后的工作台、个人聊天或平台采样图。
- 原始 API 指南、可用密钥、Cookie、登录二维码、SQLite、浏览记录、真实验收响应和 Git 历史均不属于发布输入。

## 实际平台与模型验收

发布构建的普通测试不调用付费 API，也不继承开发者的登录状态。真实 B 站、DeepSeek 及 DSH Web 模型对话需要使用者自行配置账号并显式测试。开发阶段的私有账号验收数据不附在公开仓库中，也不能代替使用者环境中的验证。

配置自己的密钥后，可用合成素材检查模型接口：

```bash
uv run python scripts/smoke_live.py --output data/live-smoke.json
```

工作台启动并完成 B 站登录后，可严格检查指定视频的字幕闭环：

```bash
uv run python scripts/subtitle_e2e.py --video-id YOUR_BV_ID --base-url http://127.0.0.1:8765
```

字幕脚本先检查服务身份，再要求真实字幕、有效时间戳、原文匹配的推荐证据、正确引用、反馈保存与排除、导出全部通过。`frames` 或 `metadata_only` 的 HTTP 200 不算字幕验收通过。该脚本会产生模型用量，并在专用验收目标中记录明确标为测试数据的评分。输出放在被忽略的运行目录，不应提交到公开仓库。

## 如何解释结果

合成语料规模小，查询与标签有明显重合，数据也由项目作者编写。上述通过结果说明约定流程与边界在当前环境中的行为，不能用于宣称真实用户满意度、线上推荐准确率、长期体验稳定性或性能提升百分比。

第二阶段应建立独立查询与人工相关性标注，比较检索、重排、成本和延迟，并对隐含偏好、否定、内容漂移等失败场景做系统评估。见[路线图](ROADMAP.md)。
