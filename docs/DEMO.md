# 工作台演示：下班后的十分钟

这份指南用合成素材演示“模糊需求 → 探索 → 证据入库 → 意图澄清 → 反馈改变推荐”。不需要个人账号，不调用真实模型。

## 启动

在项目根目录运行：

```bash
uv sync --frozen
make demo
```

打开 [本地工作台](http://127.0.0.1:8765)，确认模式为演示数据和本地规则。演示数据保存在 `data/demo/`。如果端口被占用，可改为：

```bash
CDV_PROVIDER=demo CDV_LLM=demo CDV_DATA_DIR=data/demo-8766 uv run codiscover-video serve --port 8766
```

合成素材和结构化场景见 [示例说明](../examples/README.md)。若希望直接检查机器可读结果，运行 `uv run python scripts/run_example.py`；该脚本使用临时数据库，不会预填工作台的数据。

## 1. 创建一个尚不确定的目标

点击“新建体验目标”，输入：

> 下班后想放松十分钟，但不知道适合看什么。

场景可以填写：

> 晚上独自吃饭，想有一点陪伴，但不想增加学习压力。

目标默认只手动探索。先不启用定时，便于观察一次完整流程。

## 2. 探索并查看证据

点击“探索新内容”。在“探索与设置”中查看任务阶段：规划、搜索、读取、分析与入库。任务完成后回到“与 Agent 共行”，刷新推荐。

打开任一视频的“查看证据”，区分：

- 原始内容片段与时间戳。
- Agent 的摘要与体验推断。
- 内容证据状态和置信度。

演示标题、作者和字幕是人工编写的虚构素材，没有真实播放地址。这里的置信度不表示你会喜欢它的概率。

## 3. 澄清与修正方向

输入：

> 我喜欢安静的自然观察，不喜欢高刺激和学习压力。

查看“逐渐清晰的意图”。明确偏好、排除项与待验证方向应分别呈现；也可以点击“编辑”直接修正，不必通过连续对话绕过错误理解。

继续表达一个变化，例如：

> 我也想试试轻度好奇，但暂时不想看需要记知识的科普。

规则演示只是用于观察数据与交互流程。复杂表达的理解效果应在真实模型模式和独立评估中另行检验。

## 4. 让反馈改变推荐

选择一条推荐，点击“记录体验”，给出 1 或 2 分，并写明原因，例如：

> 对下班放松来说不太合适，我希望更低负担一些。

保存后刷新推荐，该视频应从**当前目标**的候选中排除。反馈绑定目标，因此另一个“周末学习”的目标不应继承这次排除。

演示评分属于测试输入，不是真实用户满意度数据。可重复脚本还会检查目标隔离，不依赖人工判断卡片位置。

## 5. 添加自行发现的内容或自由反馈

“添加看过的视频”允许把 Agent 推荐之外的内容带入流程。在演示模式下，可输入合成 ID，例如 `demo-cook`；真实 BV 导入需要切换到 B 站数据源。

也可以直接记录此刻的感受：

> 今天比较累，熟悉的声音比新知识更重要。

自由反馈可以辅助后续规划和意图澄清，但不凭空成为某条视频的评分。

## 6. 检查任务和本地记忆

打开“探索与设置”，查看任务事件、配置状态和导出入口。可以取消或恢复适用的任务；取消后的当前网络请求可能需要先结束，才允许恢复或清除记忆。

关闭浏览器不会自动停止服务进程；如果已为目标开启定时且电脑、进程、网络继续运行，离线探索仍可进行。电脑休眠或服务退出后没有云端任务接管。

导出的 JSON 可能包含个人目标、对话和反馈。即使它不包含 API Key，也不要直接上传为公开示例。

## 切换到真实模式

按 [README 的真实模式步骤](../README.md#使用真实-b-站与-deepseek)设置自己的 API Key，并用独立的数据目录。真实模型会产生用量，平台字幕可能需要扫码登录。

先用自己选择的一条公开短视频验证：导入 → 检查证据状态 → 对话引用 → 反馈回读。不能把 HTTP 200、只有标题的记录或画面帧降级视为字幕采集成功。严格字幕验收脚本可显式运行：

```bash
uv run python scripts/subtitle_e2e.py --video-id YOUR_BV_ID
```

这会在本地建立专用验收目标并记录明确标注的测试反馈。完整工程边界和验证范围见 [架构](ARCHITECTURE.md) 与 [验证记录](VALIDATION.md)。
